# ai-project
# 🤖 AI Project – Full-Stack AI Chatbot

An intelligent full-stack AI chatbot application that combines a modern web interface with a powerful backend to provide real-time, AI-driven conversations. The project demonstrates end-to-end AI application development, including frontend development, backend API integration, and conversational AI.

---

# 📌 Overview

This project showcases the development of a production-style AI chatbot using a modern frontend and backend architecture. The chatbot is designed to provide intelligent, context-aware responses through a clean and interactive user interface.

The project follows a modular architecture, making it easy to extend with additional AI capabilities, authentication, databases, document processing, and deployment support.

# 🚀 Installation

## Clone the repository

```bash
git clone https://github.com/Gpraveenbabu/ai-project.git
```

Move into the project

```bash
cd ai-project
```

---

# Frontend Setup

Navigate to the frontend directory

```bash
cd ai-chat-bot
```

Install dependencies

```bash
npm install
```

Start the frontend

```bash
npm start
```

The frontend will be available at:

```
http://localhost:3000
```

---

# Backend Setup

Navigate to the backend

```bash
cd backend
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the environment

### macOS/Linux

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the backend

```bash
python main.py
```
